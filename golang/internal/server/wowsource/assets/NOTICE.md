# WoW source renderer

`project.js`, `project.wasm`, and `project.data` are the WebWowViewerCpp
Emscripten renderer distributed by wow.tools.local (build 1665263793).
The renderer and bundled shaders remain upstream code.

- Renderer by Deamon: https://github.com/Deamon87/WebWowViewerCpp
- Distribution by Martin Benjamins: https://github.com/Marlamin/wow.tools.local

The capture host uses only wow-converter's loaded CASC data. It requires no
wow.tools.local service or installation at runtime.
